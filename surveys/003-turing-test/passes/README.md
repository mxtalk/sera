# passes

Passes handed in for survey 003.

27 November 2026 · Daniel Tuck

Each pass is two files, the fire list filled in (`.csv`) and its details (`.md`), as [survey.md](../../../survey.md) sets out. Taskmarket passes are named `pass-<wallet>`; alternate passes are named `pass-<name>-<model>-<date>-<time>`, with the date as YYYYMMDD and the time as HHMM.
